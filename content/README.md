# Preguntes amb imatges

Una pregunta pot incloure una imatge just despres de l'enunciat:

```md
---
id: pla-xic-004
category: llocs
difficulty: mitjana
answer: A
---
# Quin edifici apareix a la fotografia?
![Façana de l'escola](/questions/escola.jpg)
A. L'escola del barri
B. El mercat
C. La biblioteca
D. El centre civic
> Explicacio que es mostra quan la resposta es correcta.
```

Les imatges s'han de desar a `public/questions/`. La ruta escrita al Markdown comenca per `/questions/`.
